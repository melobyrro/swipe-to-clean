# Security Policy

## Supported Versions

Only the latest `main` branch state is currently supported.

## Reporting a Vulnerability

Do not open a public GitHub issue for credential leaks, auth bypasses, CSRF problems, media proxy escapes, or deployment security issues.

Report privately to the maintainers first and include:

- affected version or commit
- impact summary
- reproduction steps
- suggested mitigation if known

Until a dedicated security contact exists, treat the first maintainer contact channel associated with the repository as the reporting path.
